# AI 小镇日志实时监听方案（fix-20260317-2）

> 日期: 2026-03-17
> 前置: fix-20260317.md（F-01 ~ F-08 已实现）
> 目标: 借鉴 Star-Office-UI 的 `office_sync.py` 方案，通过实时监听 OpenClaw 日志文件，让 IM 模式下也能实时显示 agent 工作状态。

## 1. 问题回顾

fix-20260317 中 IM 模式的短板：

- `CreateTownRun(source="im")` 不传 standbyAgents
- `finalizeTownRun` 是同步阻塞的，等 bridge 返回才知道谁参与了
- 任务执行期间 Town 不知道哪些 agent 在工作
- agent 小人不会实时走到工位上，只有任务结束后才短暂显示 completed

## 2. Star-Office-UI 方案核心思路

Star-Office-UI 的 `office_sync.py` 通过 `tail -F /tmp/openclaw/*.log` 实时监听 OpenClaw 运行日志，解析 JSON 日志行中的 `agent/embedded` 子系统事件，识别哪个 agent 正在工作、使用什么工具、何时完成。

### 关键信号

| 日志子系统 | 信号 | 含义 |
|---|---|---|
| `agent/embedded` | `embedded run start` | agent 接到新任务 |
| `agent/embedded` | `embedded run prompt start` | agent 正在思考（LLM 推理中） |
| `agent/embedded` | `embedded run tool start` | agent 正在使用工具 |
| `agent/embedded` | `embedded run tool end` | 工具执行完毕，继续推进 |
| `agent/embedded` | `embedded run prompt end` | 一轮思考完成 |
| `agent/embedded` | `embedded run done` | 一轮 LLM 响应结束（不是整个任务结束） |
| `diagnostic` | `lane enqueue` | 子代理任务入队（开始工作） |
| `diagnostic` | `lane task done` | 子代理任务完成（回到 idle） |

### Agent 身份识别三重策略

1. **runId 解析**: 子代理通告格式 `announce:v1:agent:<agentId>:subagent:xxx`，正则提取 agentId
2. **sessionId 文件系统反查**: 扫描 `~/.openclaw/agents/<agentId>/sessions/<sessionId>.jsonl`，建立 sessionId → agentId 映射缓存
3. **字符串匹配兜底**: 在日志原文中搜索已知 agentId

### 状态机

```
embedded run start        → executing（接到新任务）
embedded run prompt start → researching（正在思考）
embedded run tool start   → editing / executing（使用工具）
embedded run tool end     → executing（工具完毕，继续推进）
embedded run prompt end   → executing（一轮思考完成）
embedded run done         → executing（一轮响应结束，等待下一步）
lane enqueue              → executing（子代理任务入队）
lane task done            → idle（子代理任务完成）
```

注意：`embedded run done` 只是一轮 LLM 响应结束，不是整个 LANE 任务结束。只有 `lane task done` 才触发 idle。

## 3. 移植方案：Go 原生实现

Star-Office-UI 用 Python + `tail -F` + `state.json` 文件实现。我们移植到 Go 中，直接集成到 ClawPanel 后端，不需要额外进程。

### 3.1 新增文件

`internal/handler/town_logsync.go` — OpenClaw 日志实时监听引擎

### 3.2 架构

```
/tmp/openclaw/openclaw-*.log     ← OpenClaw 运行时日志
        ↓ goroutine: tail -F（Go 原生实现）
  town_logsync.go（解析 JSON 日志行）
        ↓ 识别 agent 状态变化
  更新 townSharedState.Instances  ← 直接写入内存状态
        ↓
  InvalidateTownSnapshotCache()   ← 清缓存
  BroadcastTownInvalidate(hub)    ← WS 推送前端
```

### 3.3 日志目录

OpenClaw 日志默认写入 `/tmp/openclaw/`，文件名格式 `openclaw-*.log`。
可通过环境变量 `OPENCLAW_LOG_DIR` 覆盖。

### 3.4 Session → Agent 缓存

启动时扫描 `~/.openclaw/agents/<agentId>/sessions/` 目录，建立 sessionId → agentId 映射。
遇到未知 sessionId 时动态刷新缓存。

## 4. 详细设计

### 4.1 数据结构

```go
// town_logsync.go

// agentLiveState 表示一个 agent 的实时工作状态（由日志监听推导）
type agentLiveState struct {
    AgentID   string // agent 标识
    State     string // idle / researching / executing / editing
    Detail    string // 人可读描述，如 "正在使用工具: Edit"
    RunID     string // 关联的 runId（如果能从日志中提取）
    SessionID string // 关联的 sessionId
    UpdatedAt time.Time
}

// townLogSyncer 是日志监听引擎的主结构
type townLogSyncer struct {
    cfg           *config.Config
    hub           *ws.Hub
    mu            sync.Mutex
    agentStates   map[string]*agentLiveState // agentId → live state
    sessionCache  map[string]string          // sessionId → agentId
    logDir        string                     // /tmp/openclaw
    stopCh        chan struct{}
    idleTimeout   time.Duration              // 10 分钟无活动自动回 idle
}
```

```go
// StartTownLogSyncer 启动日志监听引擎。
// 在 InitTownStore 之后、路由注册之前调用。
func StartTownLogSyncer(cfg *config.Config, hub *ws.Hub) {
    logDir := strings.TrimSpace(os.Getenv("OPENCLAW_LOG_DIR"))
    if logDir == "" {
        logDir = "/tmp/openclaw"
    }

    syncer := &townLogSyncer{
        cfg:          cfg,
        hub:          hub,
        agentStates:  make(map[string]*agentLiveState),
        sessionCache: make(map[string]string),
        logDir:       logDir,
        stopCh:       make(chan struct{}),
        idleTimeout:  10 * time.Minute,
    }

    // 启动时构建 session 缓存
    syncer.buildSessionCache()

    // 后台 goroutine: 监听日志
    go syncer.watchLoop()

    // 后台 goroutine: 定期清理超时 agent
    go syncer.cleanupLoop()
}
```

```go
func (s *townLogSyncer) buildSessionCache() {
    agentIDs, _ := loadAgentIDs(s.cfg)
    for _, agentID := range agentIDs {
        sessionsDir := resolveAgentPath(s.cfg, agentID, "sessions")
        entries, err := os.ReadDir(sessionsDir)
        if err != nil {
            continue
        }
        for _, entry := range entries {
            name := entry.Name()
            if !strings.Contains(name, ".jsonl") {
                continue
            }
            sessionID := strings.Split(name, ".")[0]
            if sessionID != "" {
                s.sessionCache[sessionID] = agentID
            }
        }
    }
    log.Printf("[TownLogSync] 已缓存 %d 个 session → agent 映射", len(s.sessionCache))
}
```

### 4.4 Agent 身份识别

```go
// identifyAgent 三重策略识别日志行属于哪个 agent
func (s *townLogSyncer) identifyAgent(runID, sessionID, rawContent string) string {
    // 策略1: runId 解析（子代理通告格式 announce:v1:agent:<id>:...）
    if runID != "" {
        re := regexp.MustCompile(`agent:([a-zA-Z0-9_-]+):`)
        if m := re.FindStringSubmatch(runID); len(m) > 1 {
            agentIDs, _ := loadAgentIDs(s.cfg)
            agentSet := toStringSet(agentIDs)
            if _, ok := agentSet[m[1]]; ok {
                return m[1]
            }
        }
    }

    // 策略2: sessionId 文件系统反查
    if sessionID != "" {
        s.mu.Lock()
        if agentID, ok := s.sessionCache[sessionID]; ok {
            s.mu.Unlock()
            return agentID
        }
        s.mu.Unlock()
        // 动态刷新
        if agentID := s.refreshSessionCache(sessionID); agentID != "" {
            return agentID
        }
    }

    // 策略3: 字符串匹配兜底
    agentIDs, _ := loadAgentIDs(s.cfg)
    lower := strings.ToLower(rawContent)
    for _, agentID := range agentIDs {
        if agentID == "main" {
            continue
        }
        if strings.Contains(lower, strings.ToLower(agentID)) {
            return agentID
        }
    }

    return "main"
}

func (s *townLogSyncer) refreshSessionCache(sessionID string) string {
    agentIDs, _ := loadAgentIDs(s.cfg)
    for _, agentID := range agentIDs {
        sessionPath := resolveAgentPath(s.cfg, agentID, "sessions", sessionID+".jsonl")
        if _, err := os.Stat(sessionPath); err == nil {
            s.mu.Lock()
            s.sessionCache[sessionID] = agentID
            s.mu.Unlock()
            log.Printf("[TownLogSync] 新发现: session %s → %s", sessionID[:min(12, len(sessionID))], agentID)
            return agentID
        }
    }
    return ""
}
```

### 4.5 日志行解析与状态更新

```go
// processLogLine 解析单行 JSON 日志，提取信号并更新 agent 状态
func (s *townLogSyncer) processLogLine(line string) {
    line = strings.TrimSpace(line)
    if !strings.HasPrefix(line, "{") {
        return
    }

    var logData map[string]interface{}
    if err := json.Unmarshal([]byte(line), &logData); err != nil {
        return
    }

    meta, _ := logData["_meta"].(map[string]interface{})
    nameRaw := toString(meta["name"])

    // 解析子系统
    subsystem := nameRaw
    if strings.HasPrefix(nameRaw, "{") {
        var nameObj map[string]interface{}
        if json.Unmarshal([]byte(nameRaw), &nameObj) == nil {
            subsystem = toString(nameObj["subsystem"])
        }
    }

    switch subsystem {
    case "agent/embedded":
        s.processEmbeddedSignal(logData)
    case "diagnostic":
        s.processDiagnosticSignal(logData)
    }
}
```

```go
// processEmbeddedSignal 处理 agent/embedded 子系统的日志信号
func (s *townLogSyncer) processEmbeddedSignal(logData map[string]interface{}) {
    msg := strings.ToLower(toString(logData["1"]))
    contentF0 := strings.ToLower(toString(logData["0"]))
    fullMsg := msg + " " + contentF0

    // 只处理 embedded run 相关信号
    if !strings.Contains(fullMsg, "embedded run") {
        return
    }

    fields := extractLogFields(msg)
    runID := firstNonEmpty(fields["runid"], fields["runId"])
    sessionID := firstNonEmpty(fields["sessionid"], fields["sessionId"])
    toolName := fields["tool"]

    raw, _ := json.Marshal(logData)
    agentID := s.identifyAgent(runID, sessionID, string(raw))

    // 严格状态机
    switch {
    case strings.Contains(fullMsg, "embedded run done"):
        // 一轮 LLM 响应结束，不是整个任务结束
        s.updateAgentState(agentID, "executing", "等待下一步指令...", runID, sessionID)

    case strings.Contains(fullMsg, "embedded run start") &&
        !strings.Contains(fullMsg, "tool") &&
        !strings.Contains(fullMsg, "prompt") &&
        !strings.Contains(fullMsg, "agent"):
        channel := firstNonEmpty(fields["messagechannel"], fields["messageChannel"])
        s.updateAgentState(agentID, "executing", fmt.Sprintf("接到新任务 (%s)...", channel), runID, sessionID)

    case strings.Contains(fullMsg, "embedded run prompt start"):
        s.updateAgentState(agentID, "researching", "正在思考分析...", runID, sessionID)

    case strings.Contains(fullMsg, "embedded run tool start"):
        detail := "正在执行工具..."
        state := "executing"
        if toolName != "" {
            detail = fmt.Sprintf("正在使用工具: %s", toolName)
            editTools := []string{"edit", "write", "replace", "multi_replace"}
            for _, kw := range editTools {
                if strings.Contains(toolName, kw) {
                    state = "editing"
                    break
                }
            }
        }
        s.updateAgentState(agentID, state, detail, runID, sessionID)

    case strings.Contains(fullMsg, "embedded run tool end"):
        s.updateAgentState(agentID, "executing", "整理返回结果...", runID, sessionID)

    case strings.Contains(fullMsg, "embedded run prompt end"):
        s.updateAgentState(agentID, "executing", "思考完成，继续处理...", runID, sessionID)
    }
}

// processDiagnosticSignal 处理 diagnostic 子系统的日志信号
func (s *townLogSyncer) processDiagnosticSignal(logData map[string]interface{}) {
    msg := toString(logData["1"])

    if !strings.Contains(msg, "lane") {
        return
    }

    // lane 事件携带 Agent 名称: lane=session:agent:<name>:main
    re := regexp.MustCompile(`lane=session:agent:([a-zA-Z0-9_-]+):`)
    m := re.FindStringSubmatch(msg)
    if len(m) < 2 {
        return
    }

    agentID := m[1]
    agentIDs, _ := loadAgentIDs(s.cfg)
    agentSet := toStringSet(agentIDs)
    if _, ok := agentSet[agentID]; !ok {
        return
    }

    switch {
    case strings.Contains(msg, "lane enqueue"):
        // 子代理任务入队 → 开始工作
        s.updateAgentState(agentID, "executing", "接到任务，启动中...", "", "")

    case strings.Contains(msg, "lane task done"):
        // 子代理任务完成 → 回到 idle
        durationRe := regexp.MustCompile(`durationMs=(\d+)`)
        dur := "?"
        if dm := durationRe.FindStringSubmatch(msg); len(dm) > 1 {
            dur = dm[1]
        }
        s.removeAgentState(agentID)
        log.Printf("[TownLogSync] %s lane 完成 (%sms) → idle", agentID, dur)
    }
}
```

### 4.6 状态更新与 WS 推送

```go
// updateAgentState 更新 agent 实时状态，并触发 snapshot 缓存失效 + WS 推送
func (s *townLogSyncer) updateAgentState(agentID, state, detail, runID, sessionID string) {
    s.mu.Lock()
    prev := s.agentStates[agentID]
    // 防抖：如果状态没变，不重复推送
    if prev != nil && prev.State == state && prev.Detail == detail {
        s.mu.Unlock()
        return
    }
    s.agentStates[agentID] = &agentLiveState{
        AgentID:   agentID,
        State:     state,
        Detail:    detail,
        RunID:     runID,
        SessionID: sessionID,
        UpdatedAt: time.Now(),
    }
    s.mu.Unlock()

    // 同步更新 townSharedState 中的 instance
    s.syncInstanceToStore(agentID, state, runID, sessionID)

    // 清缓存 + WS 推送
    InvalidateTownSnapshotCache()
    BroadcastTownInvalidate(s.hub, 0)

    log.Printf("[TownLogSync] %s → %s: %s", agentID, state, detail)
}

// removeAgentState 移除 agent 实时状态（任务完成，回到 idle）
func (s *townLogSyncer) removeAgentState(agentID string) {
    s.mu.Lock()
    delete(s.agentStates, agentID)
    s.mu.Unlock()

    // 从 store 中清理 instance（按 OFFICE.md 归位逻辑）
    s.cleanupInstanceFromStore(agentID)

    InvalidateTownSnapshotCache()
    BroadcastTownInvalidate(s.hub, 0)
}

// syncInstanceToStore 将日志监听到的 agent 状态同步到 townSharedState
// 这样 buildTownSnapshotFromState 中的 deriveTownExecutionState 就能感知到实时状态
func (s *townLogSyncer) syncInstanceToStore(agentID, state, runID, sessionID string) {
    instanceStatus := "executing" // 默认
    switch state {
    case "researching":
        instanceStatus = "thinking"
    case "editing":
        instanceStatus = "executing"
    case "executing":
        instanceStatus = "executing"
    }

    _, _ = townStore.UpdateState(nil, func(st *townSharedState) error {
        // 查找是否已有该 agent 的活跃 instance
        found := false
        for i := range st.Instances {
            if st.Instances[i].AgentID == agentID && st.Instances[i].Status != "completed" && st.Instances[i].Status != "error" {
                st.Instances[i].Status = instanceStatus
                if runID != "" {
                    st.Instances[i].RunID = runID
                }
                if sessionID != "" {
                    st.Instances[i].SessionID = sessionID
                }
                found = true
                break
            }
        }
        if !found {
            // 创建新 instance（日志监听发现了一个正在工作的 agent）
            effectiveRunID := runID
            if effectiveRunID == "" {
                effectiveRunID = fmt.Sprintf("logsync-%d", time.Now().UnixMilli())
            }
            st.Instances = prependTownInstance(st.Instances, townSharedInstance{
                ID:        fmt.Sprintf("instance-logsync-%s-%d", agentID, time.Now().UnixMilli()),
                AgentID:   agentID,
                RunID:     effectiveRunID,
                SessionID: sessionID,
                ZoneID:    fmt.Sprintf("zone-logsync-%s", agentID),
                Status:    instanceStatus,
            })

            // 同时确保有对应的 run（如果是 IM 模式，run 可能已存在）
            hasRun := false
            for _, r := range st.Runs {
                if r.Status == "running" {
                    // 把这个 agent 加入参与者
                    alreadyIn := false
                    for _, pid := range r.ParticipantAgentIDs {
                        if pid == agentID {
                            alreadyIn = true
                            break
                        }
                    }
                    if !alreadyIn {
                        r.ParticipantAgentIDs = append(r.ParticipantAgentIDs, agentID)
                    }
                    hasRun = true
                    break
                }
            }
            if !hasRun {
                // 没有活跃 run（可能是 IM 模式下 openclaw-main 自己发起的子任务）
                // 不创建 run，只创建 instance 就够了
                // deriveTownExecutionState 只需要 instance + run 都存在才判定 busy
                // 所以这里需要创建一个虚拟 run
                virtualRun := townSharedRun{
                    ID:                  effectiveRunID,
                    Title:               fmt.Sprintf("%s 正在工作", agentID),
                    Source:              "logsync",
                    Status:              "running",
                    CreatedAt:           time.Now().UnixMilli(),
                    UpdatedAt:           time.Now().UnixMilli(),
                    ParticipantAgentIDs: []string{agentID},
                }
                st.Runs = prependTownRun(st.Runs, virtualRun)
            }
        }
        return nil
    })
}
```

```go
// cleanupInstanceFromStore 清理 agent 的 instance（lane task done 时调用）
func (s *townLogSyncer) cleanupInstanceFromStore(agentID string) {
    officeSet := OfficeMemberSet(s.cfg)

    _, _ = townStore.UpdateState(nil, func(st *townSharedState) error {
        // 清理该 agent 的 logsync instance
        cleaned := st.Instances[:0]
        for _, inst := range st.Instances {
            if inst.AgentID == agentID && strings.HasPrefix(inst.ID, "instance-logsync-") {
                if officeSet[agentID] {
                    inst.Status = "completed"
                    cleaned = append(cleaned, inst)
                }
                // 不在 OFFICE.md → 删除 instance，回主镇
                continue
            }
            cleaned = append(cleaned, inst)
        }
        st.Instances = cleaned

        // 清理 logsync 虚拟 run（如果所有参与者都完成了）
        for i := range st.Runs {
            if strings.HasPrefix(st.Runs[i].ID, "logsync-") && st.Runs[i].Status == "running" {
                allDone := true
                for _, pid := range st.Runs[i].ParticipantAgentIDs {
                    if _, exists := s.agentStates[pid]; exists {
                        allDone = false
                        break
                    }
                }
                if allDone {
                    st.Runs[i].Status = "completed"
                    st.Runs[i].UpdatedAt = time.Now().UnixMilli()
                }
            }
        }
        return nil
    })
}
```

```go
// watchLoop 持续监听日志目录中的所有 .log 文件
func (s *townLogSyncer) watchLoop() {
    for {
        select {
        case <-s.stopCh:
            return
        default:
        }

        if _, err := os.Stat(s.logDir); os.IsNotExist(err) {
            log.Printf("[TownLogSync] 日志目录 %s 不存在，等待...", s.logDir)
            time.Sleep(5 * time.Second)
            continue
        }

        logFiles := s.findLogFiles()
        if len(logFiles) == 0 {
            log.Printf("[TownLogSync] 未找到日志文件，等待...")
            time.Sleep(5 * time.Second)
            continue
        }

        log.Printf("[TownLogSync] 开始监控 %d 个日志文件", len(logFiles))

        // 使用 tail -F 同时监控所有文件（跟 Star-Office-UI 一样）
        args := append([]string{"-F", "-n", "0"}, logFiles...)
        cmd := exec.CommandContext(context.Background(), "tail", args...)
        stdout, err := cmd.StdoutPipe()
        if err != nil {
            log.Printf("[TownLogSync] 创建 tail 管道失败: %v", err)
            time.Sleep(5 * time.Second)
            continue
        }

        if err := cmd.Start(); err != nil {
            log.Printf("[TownLogSync] 启动 tail 失败: %v", err)
            time.Sleep(5 * time.Second)
            continue
        }

        scanner := bufio.NewScanner(stdout)
        scanner.Buffer(make([]byte, 0, 256*1024), 256*1024) // 256KB 行缓冲
        for scanner.Scan() {
            line := scanner.Text()
            // tail -F 多文件模式会输出 "==> filename <==" 标记，跳过
            if strings.HasPrefix(line, "==>") && strings.Contains(line, "<==") {
                continue
            }
            s.processLogLine(line)
        }

        _ = cmd.Wait()
        log.Printf("[TownLogSync] tail 进程退出，5 秒后重启...")
        time.Sleep(5 * time.Second)
    }
}

func (s *townLogSyncer) findLogFiles() []string {
    entries, err := os.ReadDir(s.logDir)
    if err != nil {
        return nil
    }
    var files []string
    for _, entry := range entries {
        name := entry.Name()
        if strings.HasPrefix(name, "openclaw-") && strings.HasSuffix(name, ".log") {
            files = append(files, filepath.Join(s.logDir, name))
        }
    }
    sort.Strings(files)
    return files
}
```

### 4.8 超时清理

```go
// cleanupLoop 定期清理超时的 agent 状态
// 防止日志丢失导致 agent 永远卡在 busy 状态
func (s *townLogSyncer) cleanupLoop() {
    ticker := time.NewTicker(30 * time.Second)
    defer ticker.Stop()

    for {
        select {
        case <-s.stopCh:
            return
        case <-ticker.C:
            s.cleanupStaleAgents()
        }
    }
}

func (s *townLogSyncer) cleanupStaleAgents() {
    now := time.Now()
    s.mu.Lock()
    var stale []string
    for agentID, state := range s.agentStates {
        if now.Sub(state.UpdatedAt) > s.idleTimeout {
            stale = append(stale, agentID)
        }
    }
    for _, agentID := range stale {
        delete(s.agentStates, agentID)
    }
    s.mu.Unlock()

    if len(stale) > 0 {
        for _, agentID := range stale {
            s.cleanupInstanceFromStore(agentID)
            log.Printf("[TownLogSync] %s 超时 (%v)，自动回到 idle", agentID, s.idleTimeout)
        }
        InvalidateTownSnapshotCache()
        BroadcastTownInvalidate(s.hub, 0)
    }
}
```

### 4.9 辅助函数

```go
func extractLogFields(msg string) map[string]string {
    fields := make(map[string]string)
    re := regexp.MustCompile(`(\w+)=([^\s]+)`)
    for _, m := range re.FindAllStringSubmatch(msg, -1) {
        fields[m[1]] = m[2]
    }
    return fields
}

func firstNonEmpty(values ...string) string {
    for _, v := range values {
        if strings.TrimSpace(v) != "" {
            return strings.TrimSpace(v)
        }
    }
    return ""
}

func toStringSet(ids []string) map[string]struct{} {
```

### 5.2 与现有 finalizeTownRun 的协作

日志监听和 bridge 返回是两条独立的状态更新路径：

```
路径 A（现有）: finalizeTownRun → bridge 返回 → 更新 run/instance → 归位
路径 B（新增）: 日志监听 → 实时更新 instance → lane task done → 清理

时间线:
  t0: CreateTownRun → bridge 开始执行
  t1: 日志监听发现 agent 开始工作 → 创建 instance → 前端看到 agent 走到工位 ✓
  t2: 日志监听发现 agent 使用工具 → 更新 instance 状态 → 前端看到状态变化 ✓
  t3: 日志监听发现 lane task done → 清理 instance → agent 归位
  t4: bridge 返回 → finalizeTownRun 更新 run 状态 → 最终归位
```

两条路径可能有竞争，但不会冲突：
- 路径 B 创建的 instance ID 带 `logsync-` 前缀，路径 A 创建的不带
- `finalizeTownRun` 的 F-08 归位逻辑会清理所有该 run 的 instance
- 如果路径 B 先清理了，路径 A 再清理时是幂等的（找不到就跳过）

### 5.3 防抖策略

- `updateAgentState` 中检查状态是否真的变了，没变不推送
- WS invalidate 只是信号，前端会合并短时间内的多次 invalidate
- snapshot 缓存 TTL 3 秒，高频日志不会导致高频 snapshot 构建

## 8. 风险点

1. **日志格式耦合**: 依赖 OpenClaw 日志的 JSON 格式和 `agent/embedded` 子系统命名。OpenClaw 升级改日志格式会导致监听失效。缓解：日志解析做容错处理，解析失败静默跳过。

2. **日志目录不存在**: OpenClaw 未运行时 `/tmp/openclaw` 可能不存在。缓解：`watchLoop` 中已有重试逻辑。

3. **tail 进程泄漏**: 如果 ClawPanel 异常退出，tail 子进程可能残留。缓解：使用 `context.WithCancel` 管理 tail 生命周期，ClawPanel 退出时 cancel。

4. **高频日志导致 WS 风暴**: agent 密集使用工具时日志量大。缓解：`updateAgentState` 有防抖（状态没变不推送），前端也有 invalidate 合并。

5. **logsync instance 与 bridge instance 竞争**: 两条路径可能同时操作同一个 agent 的 instance。缓解：logsync instance 带 `logsync-` 前缀区分，`finalizeTownRun` 清理时按 runID 匹配，不会误删 logsync instance。

6. **macOS 上 /tmp 清理**: macOS 会定期清理 /tmp。缓解：OpenClaw 运行时会持续写入，文件不会被清理。如果 OpenClaw 重启，日志文件会重新创建，tail -F 会自动跟踪新文件。
