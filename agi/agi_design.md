# 超级AI大脑 (Super AI Brain) 系统设计文档

## 1. 系统愿景与定位

"超级AI大脑"是一个具备自主信息感知、长效图谱记忆、深度逻辑推演，并深度融合"人类在环 (Human-in-the-Loop)"交互模式的通用型战略决策支持系统。

本系统旨在协助人类进行最精密的商业计算、最深度的底层挖掘，以及寻找具有破坏性创新的最优解。它不仅是一个问答引擎，更是一个动态的、可视化的、基于概率流转的推演沙盘。

## 2. 总体系统架构 (System Architecture)

系统整体分为四个核心层级：

1. **感知与清洗层 (Perception & Cleansing)**：负责从全网或指定私有库不断获取新信息，进行降噪与实体抽取。
2. **记忆与关系层 (Memory & Graph)**：结合向量数据库与图数据库（GraphRAG），实现概念的模糊搜索与精准逻辑溯源。
3. **推演与计算层 (Reasoning & Calculus)**：大语言模型 (LLM) 思维树 (ToT) 与蒙特卡洛树搜索 (MCTS) 的融合引擎。
4. **交互与共创层 (Interaction & Co-creation)**：可视化的动态概率决策树，实现人类直觉与AI算力的双向赋能。

## 3. 核心功能模块设计

### 3.1 动态概率推演树 (Dynamic Probability Tree - 核心引擎)

这是人机协同的最前线，采用树状拓扑结构展示推演路径。

- **节点 (Node)**：代表一个具体的事件、商业策略或创新想法。
- **边 (Edge)**：代表节点之间的逻辑因果关系及转移概率（条件概率）。
- **水波纹联动机制 (Ripple Effect)**：当人类或AI修改某一节点的概率，或进行剪枝操作时，触发全局树图的贝叶斯概率重算。

**绝对概率公式：**

> 当前节点绝对发生率 = 父节点绝对发生率 × 当前节点条件概率

**动态归一化：**

> 当某一同级节点被"剪枝"时，系统自动将剩余同级节点的条件概率按比例放大，使同级总概率维持在 100%。

### 3.2 混合记忆引擎 (GraphRAG Memory)

摒弃传统的纯文本记忆，采用双轨制数据库以解决大模型幻觉与逻辑断层。

- **向量数据库 (Vector DB)**：存储节点文本特征，用于处理"发散性"思维，如："寻找与新能源降价相关的历史事件"。
- **图数据库 (Graph DB - 如 Neo4j)**：强制实体规范化（Schema-driven），存储严密的因果逻辑链。

**记忆衰减与反向修正 (Belief Revision)：**

为图谱中的每一条边赋予"置信度权重"。当推演树验证某条路径无效时，沿图谱反向传播，降低历史节点权重；低于阈值则自动归档（遗忘机制）。

### 3.3 多智能体对抗推演网络 (Multi-Agent Adversarial Network)

平衡系统的"发散创新"与"收敛求证"。

- **"红方"生成者智能体 (高温度系数)**：扮演"疯狂科学家"。专门负责在当前节点下，生成反直觉的、破坏性创新的子节点分支。
- **"蓝方"批判者智能体 (低温度系数)**：扮演"严苛风控官"。根据图谱历史数据和底层物理/商业逻辑，对红方生成的节点进行概率打分和漏洞攻击。

### 3.4 算力与成本路由中心 (Cost-aware Routing)

防止推演过程陷入"算力黑洞"。

- **大小模型动态路由：**
  - 基础信息抽取、洗稿、同义词合并：调用低成本开源模型（如 Llama-3-8B / Qwen）或轻量级 API。
  - 高级逻辑判定、概率打分、战略创新节点生成：调用顶级闭源模型（如 Gemini Pro / GPT-4o / Claude 3.5 Sonnet）。
- **语义缓存 (Semantic Cache)**：历史推演过的相似子结构直接从缓存读取，跳过模型计算。
- **无情剪枝 (Aggressive Pruning)**：设定绝对概率红线（如 <5%）。一旦某条分支的全局发生概率极低，冻结该分支，停止下发算力。

## 4. 关键交互流程 (User Workflow)

1. **初始命题输入**：用户输入一个宏大命题（例："未来三年固态电池对现有新能源车企的利润影响"）。
2. **AI 发散与建树**：AI 结合知识图谱，向下生成 3-5 个一级推演分支，并赋予初始条件概率。
3. **人类干预与对齐**：
   - **手动调参**：用户认为某分支概率过低，拖动滑块将其从 20% 拉升至 60%。
   - **全局重算**：系统触发 Ripple Effect，瞬间重新分配并渲染所有下游节点的存活概率。
   - **强制剪枝**：用户凭借独家信息，一键删去"电池材料价格崩盘"分支，系统重新归一化剩余分支。
   - **注入灵感**：用户手动添加一个空白节点输入"突发地缘政治禁运"，AI 立即接管，计算该节点的概率并生成其后续连锁反应。
4. **最终输出与执行**：经过数轮人机博弈剪枝，系统高亮出一条"绝对概率最高"或"收益期望最大"的黄金路径，并附带全程的逻辑溯源图谱。

## 5. 演进路线图 (Roadmap)

### Phase 1: MVP 最小可行性产品 (单机沙盒版)

- **目标**：跑通"动态概率树"的核心算法与人机交互。
- **动作**：
  - 不连接外网爬虫，使用纯前端可视化库 (React Flow) + 本地 Python 贝叶斯概率推演引擎。
  - 用户手动输入背景，验证概率水波纹和剪枝重算逻辑。

### Phase 2: 领域专家系统 (私有数据接入)

- **目标**：接入记忆与真实推演能力。
- **动作**：
  - 引入 GraphRAG，接入行业研究报告和私有业务数据。
  - 实现大模型对子节点的自动生成与初步概率打分机制。

### Phase 3: 自主进化超级大脑 (全功能体)

- **目标**：实现 24/7 自动化运行与自我迭代。
- **动作**：
  - 加入全网自动化爬虫监控，引入红蓝对抗多智能体。
  - 系统能够在你睡觉时，针对高关注度的节点进行自动 MCTS 深度推演，并在第二天早上为你呈现新的黄金路径。
